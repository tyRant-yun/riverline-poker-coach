## HTTP contract

- `POST /v1/tables`: `{schemaVersion, commandId, seed?, heroSeat?, botProfile?, sessionId?}`.  Creates the fixed 6-max 100BB no-ante/no-rake table and advances bots to the hero or terminal state.
- `GET /v1/tables/{sessionId}`: reconnects to the durable authority projection.
- `POST /v1/tables/{sessionId}/actions`: `{schemaVersion, commandId, handId, expectedRevision, action, amount?, amountSemantics}`.  Only accepts a legal hero turn, then advances bots.
- `POST /v1/tables/{sessionId}/hands`: `{schemaVersion, commandId, expectedRevision}`.  Opens the successor only after a completed hand.

Every successful command returns `{schemaVersion, requestId, idempotent, table}`.  `table` contains session/hand IDs, hand sequence, button, revision, public board/pot/street/seats/commitments/history, the hero's cards and legal actions only, current actor, terminal result, and sanitized bot decision provenance.  It omits all opponent hole cards, deck state, and RNG seed.  Reused commands return the current projection; changed intent under the same command ID, stale hand/revision, or non-hero turns return stable error codes.

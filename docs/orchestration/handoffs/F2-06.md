## UI contract

The AppShell **持续牌桌** tab creates the F2-04 fixed table with a selected
`cautious`, `balanced`, or `aggressive` profile.  It saves the returned
`sessionId` locally and reconnects by `GET /v1/tables/{sessionId}` after reload.
Buttons are rendered solely from `heroLegalActions`; amount inputs use the
server-provided min/max and action semantics travel back unchanged.  The UI
does not derive poker rules, outcomes, sizing limits, cards, or stacks.

The page displays only `heroHoleCards`; all other seats pass an empty card list
to the shared table component and render face-down.  Its `data-testid` hooks
include `continuous-table-page`, `bot-profile`, `create-continuous-table`,
`continuous-table-status`, `hero-legal-actions`, `hero-action-*`, `next-hand`,
`table-action-history`, `bot-provenance`, and `advisor-sidebar-placeholder`.

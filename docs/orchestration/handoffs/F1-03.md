  - HandStartedPayloadV1 forces starting_stacks keys to contiguous 0..table_size-1, validates every later seat ID as less than table_size, and has no active-seat set. Therefore a 6-max hand with seats 1/2 sitting out cannot both retain session seat IDs 0/3/4/5 in events and tell replay/PokerKit that only those four seats participate.

## Statistical semantics

Only `HandStarted.activeSeatIds` receive dealt, VPIP, and PFR opportunities, so zero-stack or sitting-out table seats never enter denominators. VPIP is one or more voluntary preflop call/bet/raise actions per hand; PFR is one or more preflop bet/raise actions per hand. A 3-bet is only the first raise by another seat after the first preflop open raise; its denominator is that seat's first recorded preflop action after the open. Forced blinds never create VPIP/PFR actions.

The F1-04 runner persists a per-hand cursor/snapshot before aggregation. The aggregate additionally has a `(session_id, hand_id)` unique checkpoint, so repeated delivery, a runner restart, and multiple voluntary actions do not double count. `rebuild()` discards both aggregate and hand cursor caches, then rereads the supplied authoritative hand streams; the focused test proves the rebuilt payload and fingerprint equal the incremental result.

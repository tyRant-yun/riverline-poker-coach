# Riverline v0.2.0 — 可观测德州扑克认知模拟器 MVP

发布日期：2026-08-22

发布形态：源码仓库

发布分支：`main`

## 产品状态

v0.2.0 提供一条可体验的 6-max 人机训练纵向切片：

- 连续牌桌、随机发牌、合法动作、摊牌、下一手、Bot 清台补码和断线恢复。
- 多档 Bot provider 与安全降级；座位附近显示动作，播放队列保留可读节奏。
- Hero 决策工作区同时呈现 Advisor、策略来源、置信等级、候选动作和高对比度 Range Belief。
- 完成手牌自动生成安全复盘，并累计 VPIP、PFR 等会话统计。
- Theory Truth Source 统一约束 Solver、Advisor、Range 和教学解释，避免彼此给出相互矛盾的伪精确答案。

## 理论强度与诚实边界

当前可声明的策略覆盖是：B 级已覆盖翻前 artifact，以及受限的 HU river jam L2。默认 provider 的发布基准覆盖 13 个声明点；复杂 turn、多路翻后、不安全尺度或未拥有的节点会返回 C/unsupported。

本版本不是完整 6-max GTO/Nash Solver。C/unsupported 场景不会伪造策略频率、EV、推荐尺度、完整范围或动作建议。界面中的置信等级和证据来源属于产品语义，而非装饰性标签。

## 最舒适的本地体验

在 Windows PowerShell 中从仓库根目录执行：

```powershell
.\scripts\start-riverline.ps1
```

启动器默认使用 SQLite 和无 Redis 模式，等待 API 与网页 ready 后自动打开浏览器。重复执行会复用已验证的实例。结束体验：

```powershell
.\scripts\stop-riverline.ps1
```

停止器只终止身份匹配的 Riverline 进程树；重复停止安全。首次运行前需安装 Python 3.13 项目依赖并在 `frontend` 执行 `npm ci`。

## 发布限制

`docs/provenance/sbom.json` 对 `source_repository_release` 判定为 PASS，但对 `bundled_binary_container_release` 判定为 FAIL。Python artifact 完整性和 Sharp/libvips 的捆绑二进制、notices 与 corresponding-source handling 尚未闭环，因此：

- 本 Release 只发布 Git tag 和源码，不附带二进制、安装包或容器镜像。
- Docker Compose 仅用于开发/集成验证，不代表生产就绪。
- SaaS 多租户、鉴权计费、租户隔离、托管数据库与生产恢复属于后续产品化阶段。
